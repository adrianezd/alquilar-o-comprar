# ¿Alquilar o comprar?

Calculadora que compara alquilar y comprar vivienda año a año: hipoteca, entrada, impuestos, gastos, subida del alquiler y rentabilidad del dinero invertido.

Sitio: https://adrianezd.github.io/alquilar-o-comprar/

Los parámetros por defecto (ITP, gastos, rentabilidad) están en `script.js`.
